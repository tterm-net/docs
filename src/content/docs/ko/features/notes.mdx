터미널이 머신에 있듯이 노트는 프로젝트의 폴더에 있어요. 런북, 접속 정보, 체크리스트를 관련된 머신 바로 옆에 둘 수 있어요. 노트는 제목과 블록으로 이루어지고, 그 자리에서 바로 쓰며, 저장은 저절로 돼요.

## 폴더

사이드바에서는 프로젝트마다 머신 아래에 **노트**가 있어요. **노트** 옆의 **+** 버튼으로 폴더를 만들어요. 이름을 정하고 **폴더 만들기**를 누르세요. 폴더 옆의 **+** 버튼은 그 폴더에 새 노트를 별도의 탭으로 열어요. 폴더 자체를 클릭하면 접히거나 펼쳐지기만 해요. 프로젝트 페이지에는 같은 기능이 버튼으로 있어요. **새 폴더**, 그리고 폴더마다 **새 노트**예요.

프로젝트 페이지에서 폴더 옆의 **⋯** 메뉴에는 **폴더 이름 바꾸기**와 **폴더 삭제**가 있어요. 폴더는 안에 든 노트와 함께 삭제돼요. 창에 그 노트들이 나오니, 남기고 싶은 노트는 먼저 다른 곳으로 옮기세요.

지금은 모든 프로젝트에 본인 한 사람만 있어서 노트도 본인만 볼 수 있고, 프로젝트의 노트와 폴더는 모두 본인이 쓰고 옮기고 삭제해요. 노트 제목 아래에도 그렇게 표시돼요: **나만 볼 수 있음**.

## 쓰기

새 노트는 제목에 커서가 놓인 채로 열리고, **Enter**를 누르면 본문으로 넘어가요. 본문은 블록으로 이루어져요: 텍스트, 제목, 목록 항목, 체크리스트 항목, 코드, 구분선. **Enter**는 새 블록을 시작하고, 빈 항목에서 누르면 목록이 끝나요.

블록 맨 앞에 Markdown을 입력하면 블록이 그 뜻대로 바뀌어요:

| 블록 맨 앞에 입력하는 것 | 바뀌는 블록 |
| --- | --- |
| `#` 뒤에 공백 | 제목 |
| `-` 뒤에 공백, 또는 `1.` 뒤에 공백 | 목록 항목 |
| `- [ ]` 뒤에 공백 | 체크리스트 항목, `- [x]`로 쓰면 체크된 항목 |
| `` ``` `` | 코드 |
| `---` | 구분선 |

블록의 다른 곳에서는 Markdown이 입력한 그대로 남아요. 빈 줄에서 **/** 키를 누르면 같은 블록을 목록에서 고를 수 있어요: **체크리스트**, **제목**, **목록**, **코드**, **구분선**, **텍스트**. 이어서 글자를 입력하면 목록이 좁혀지고, 화살표 키로 이동하고, **Enter**로 골라요. 여러 줄짜리 텍스트를 붙여 넣으면 블록으로 바뀌고, 그 안의 Markdown도 같은 방식으로 읽혀요.

## 코드와 체크리스트

코드 블록은 줄을 그대로 유지해요. 코드 블록 안에서 **Enter**는 새 줄을 시작하고, **Tab**은 공백 두 칸을 넣어요. Mac에서는 **⌘Enter**(다른 시스템에서는 **Ctrl+Enter**)를 누르면 코드 블록에서 나와 아래에 새 블록이 생겨요. 코드 블록에 붙여 넣은 텍스트는 그대로 남아요. 모서리의 **복사**를 누르면 코드가 복사되고, 잠깐 동안 **복사됨**이 표시돼요.

체크리스트 항목은 체크 상자를 눌러 체크해요. 체크는 바로 저장되고, 항목 옆에는 누가 언제 체크했는지 나와요. 오늘이면 **나 · 10:02**, 그 전이면 날짜가 나와요. 사이드바에는 체크리스트가 얼마나 진행됐는지 2/5처럼 나오고, 프로젝트 페이지에는 **2/5 완료**라고 나와요.

## 저장

노트는 입력을 멈추고 잠시 뒤에 저절로 저장돼요. 저장 상태는 탭 오른쪽에 표시돼요: **저장 중…**, **저장됨**, **저장 안 됨: 연결 없음**.

같은 노트를 두 기기에서 동시에 써도 양쪽에서 바꾼 내용이 모두 남아요. 저장할 때마다 그사이 저장된 내용과 블록 단위로 합쳐지거든요. 같은 블록이나 제목을 양쪽에서 바꿨을 때만 그 부분에 무엇을 남길지 물어봐요: **내 버전 유지** 또는 **다른 버전 유지**. 나머지는 양쪽 내용이 모두 남아요. 이렇게 합치기 위해 tTerm은 노트마다 최근 50개 버전을 보관해요.

연결이 없으면 입력한 내용은 저장될 때까지 이 브라우저에 보관되고, 페이지는 계속 저장을 시도해요. 탭을 닫거나 페이지를 새로고침해도 노트를 다시 열면 내용이 돌아와요: **이 노트에 입력했지만 저장되지 않았던 내용을 되살렸어요.**

:::caution[로그아웃하면 사라져요]
**로그아웃**하면 노트에 입력했지만 아직 저장되지 않은 내용이 이 브라우저에서 사라져요.
:::

## 옮기기, 복사, 삭제

나머지 기능은 노트 옆의 **⋯** 메뉴에 있어요. 프로젝트 페이지에서도, 노트 탭 위쪽에서도 열 수 있어요:

- **폴더** – 프로젝트의 폴더 목록이에요. 노트가 있는 폴더에 체크 표시가 있고, 다른 폴더를 클릭하면 노트가 그리로 옮겨져요. 프로젝트에 폴더가 두 개 이상 있을 때 나타나요.
- **다른 프로젝트로 이동…** – 다른 프로젝트와 그 폴더가 창에 나와요. 폴더를 고르고, 예를 들어 **런북 폴더로 이동**을 누르세요. 폴더가 없는 프로젝트에서는 노트가 있던 폴더와 같은 이름의 새 폴더를 제안해요. 노트의 제목, 내용, 기록이 함께 옮겨지고, 체크 표시와 체크한 사람 정보도 그대로 따라가요.
- **Markdown으로 복사** – 노트 전체를 복사해요. 노트 제목은 가장 높은 단계의 제목이 돼요.
- **노트 삭제** – 먼저 확인을 받아요. 삭제한 노트는 되살릴 수 없어요.

검색으로도 노트를 찾을 수 있어요. 검색어를 `n:`으로 시작하세요. [검색](../search/)을 참고하세요.

## 로그

사이드바에서 **로그**는 프로젝트의 폴더 중 맨 앞에 있고, **tTerm이 기록** 표시가 붙어 있어요. 여기에는 프로젝트의 머신마다 로그가 하나씩 있어요. tTerm을 통해 그 머신에서 실행된 모든 명령이 하루 단위로, 명령 아래 추가한 노트와 함께 담겨요. 로그는 tTerm이 기록하고, 아무도 바꿀 수 없어요. 로그 줄은 1년, 명령이 출력한 내용은 30일 동안 보관돼요. 자세한 내용은 [머신 로그](../log/)를 참고하세요.
