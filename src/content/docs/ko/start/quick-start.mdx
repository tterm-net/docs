---

로그인하고 첫 머신을 추가해 첫 명령을 실행하기까지 5분이면 충분해요. 브라우저, 그리고 Linux 서버나 터미널에서 명령을 실행할 수 있는 컴퓨터가 필요해요.

<Steps>

1. **로그인.** [app.tterm.net](https://app.tterm.net)을 열고 이메일을 입력하면 메일로 코드가 와요. 처음 로그인할 때는 이름을 묻고, 이 브라우저에서 쓸 네 자리 간편 코드를 만들어 달라고 해요.

   <Screenshot name="signin-email" alt="새 브라우저에서 로그인할 때: ‘로그인’ 화면에 이메일 anna@example.com이 입력돼 있고, ‘코드 받기’ 버튼이 있어요." />

2. **머신 추가.** 사이드바에서 **머신** 옆의 **+** 버튼을 누르고 **서버** 또는 **컴퓨터**를 고르세요. 그러면 명령이 나타나요:

   ```sh title="서버에서, root 또는 sudo 권한이 있는 사용자로"
   curl -sSL https://connect.tterm.net/s/<token> | sudo sh
   ```

   명령은 앞으로 10분 동안 한 번만 쓸 수 있어요. 스크립트가 끝나는 대로 서버가 프로젝트에 나타나요. 보통 1분이면 돼요.

   <Screenshot name="add-server" alt="‘서버’를 고른 ‘머신 추가’ 창: 서버에서 실행할 일회용 명령과 ‘복사’ 버튼이 있고, tTerm Web이 서버를 기다리고 있어요." />

3. **터미널 열기.** 사이드바에서 머신 옆의 **+** 버튼을 누르세요. 터미널이 탭으로 열려요. 평소 쓰던 셸과 프로그램, sudo까지 그대로예요.

4. **명령 입력.** 예를 들어 `uptime`을 입력해 보세요. 결과는 출력, 종료 코드, 시간, 폴더, 브랜치가 담긴 블록으로 돌아와요. 탭은 닫아도 돼요. 터미널은 계속 실행돼요.

</Steps>

:::note[서버 대신 컴퓨터라면]
컴퓨터에는 따로 명령이 있고, sudo 없이 실행해요. 자세한 내용은 [컴퓨터](../../machines/computers/) 페이지를 보세요.
:::

:::tip[내 Mac의 서버를 한 번에]
내 Mac에서 SSH로 접속하는 서버는 키와 함께 한꺼번에 가져올 수 있고, 서버에서 따로 실행할 것도 없어요. 자세한 내용은 [클라우드로 옮기기](../../local/move-to-cloud/) 페이지를 보세요.
:::
