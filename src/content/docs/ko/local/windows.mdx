Windows용 로컬 터미널은 준비 중이에요. 나오면 저희 [채널](https://t.me/tTermBlog)과 [블로그](https://tterm.net/ko/blog/)에서 알려 드릴게요.

## 지금 할 수 있는 일

- **클라우드 터미널**은 Windows의 모든 브라우저에서 작동해요. [app.tterm.net](https://app.tterm.net)을 열면 모든 서버와 컴퓨터를 바로 쓸 수 있어요.
- Windows 컴퓨터는 아직 머신으로 추가할 수 없어요. Linux 서버와 macOS나 Linux 컴퓨터는 추가할 수 있어요: [서버](../../machines/servers/), [컴퓨터](../../machines/computers/).
