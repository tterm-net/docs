The local terminal for Linux is in the works. When it is out, we will say so in our [channel](https://t.me/tTermBlog) and on the [blog](https://tterm.net/blog/).

## Right now

- **A Linux computer** can join the cloud: a small agent goes in with one command, and the computer's terminals open from any browser. See [Computer](../../machines/computers/).
- **The cloud terminal** works in any browser on Linux, at [app.tterm.net](https://app.tterm.net).
