Le terminal local pour Windows est en préparation. Quand il sortira, nous l’annoncerons sur notre [canal](https://t.me/tTermBlog) et sur le [blog](https://tterm.net/fr/blog/).

## Dès maintenant

- **Le terminal dans le cloud** fonctionne dans n’importe quel navigateur sous Windows : ouvrez [app.tterm.net](https://app.tterm.net), et tous vos serveurs et vos ordinateurs sont à portée de main.
- Un ordinateur sous Windows ne peut pas encore être ajouté comme machine. Les serveurs Linux et les ordinateurs sous macOS ou Linux, oui : un [serveur](../../machines/servers/), un [ordinateur](../../machines/computers/).
