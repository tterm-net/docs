Le terminal local pour Linux est en préparation. Quand il sortira, nous l’annoncerons sur notre [canal](https://t.me/tTermBlog) et sur le [blog](https://tterm.net/fr/blog/).

## Dès maintenant

- **Un ordinateur sous Linux** peut rejoindre le cloud : un petit agent s’installe avec une seule commande, et les terminaux de cet ordinateur s’ouvrent depuis n’importe quel navigateur. Voir [Ordinateur](../../machines/computers/).
- **Le terminal dans le cloud** fonctionne dans n’importe quel navigateur sous Linux, sur [app.tterm.net](https://app.tterm.net).
