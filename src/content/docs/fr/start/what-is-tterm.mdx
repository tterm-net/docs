tTerm est le terminal dans le cloud pour vos serveurs et vos ordinateurs. Les machines restent les vôtres, et les terminaux, l’historique des commandes et les notes vivent dans le cloud. Fermez votre ordinateur portable en pleine compilation, ouvrez votre téléphone, la compilation tourne toujours. Aucune clé sur l’appareil, aucun port ouvert nécessaire.

## Où travailler

- **Le terminal dans le cloud, tTerm Web** – dans votre navigateur, sur [app.tterm.net](https://app.tterm.net). Toutes vos machines, tous vos terminaux et toutes vos notes depuis un portable, une tablette ou un téléphone.
- **Le terminal local** – une application pour le Mac : les shells de cet ordinateur et tout le cloud dans une seule fenêtre. Elle fonctionne aussi sans compte : [la version Mac](../../local/mac/). Les versions pour Windows et Linux sont en préparation.
- **Le bot Telegram** – un terminal directement dans le chat, [@tTermNetBot](https://t.me/tTermNetBot). Pour l’instant, il vit à part du web.

## Les idées principales

- **Projet** – les machines et les notes ensemble. Tout le monde a le projet Personal, et vous pouvez créer les vôtres à côté, chacun avec son code et sa couleur.
- **Machine** – un serveur Linux connecté en SSH, ou un ordinateur sous macOS ou Linux avec un petit agent.
- **Terminal** – un vrai shell sur la machine : bash ou zsh, selon ce qui y est installé. Il vit dans le cloud, pas dans un onglet : fermez l’onglet, le terminal continue de tourner.
- **Bloc** – une commande avec sa sortie, son code de retour, l’heure, le répertoire et la branche git. Un bloc se copie, se relance et se retrouve par la recherche.
- **Note** – du Markdown dans les dossiers du projet : check-lists, commandes et modes d’emploi à côté des machines qu’ils concernent.

:::tip[Gratuit pendant la bêta]
Tout ce qui existe aujourd’hui, sans rien payer : jusqu’à 50 machines et jusqu’à 24 terminaux ouverts. Les offres payantes viendront plus tard, et nous en parlerons à l’avance.
:::
