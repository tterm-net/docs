Vous vous connectez à tTerm Web avec un code reçu par e-mail. Sur un appareil de confiance, un code court à quatre chiffres vous permet ensuite de revenir.

## Se connecter avec un code

<Steps>

1. Ouvrez [app.tterm.net](https://app.tterm.net), saisissez votre adresse e-mail et appuyez sur **Recevoir un code**. Six chiffres arrivent par e-mail.

2. Saisissez-les dans le même navigateur : le code ne fonctionne que là, pendant 10 minutes, avec cinq essais. Au bout d’une minute, vous pouvez appuyer sur **Envoyer un nouveau code**, et le code précédent cesse de fonctionner.

3. La première fois, la page demande **Votre nom** et une case à cocher, **J’accepte les Conditions d’utilisation et la Politique de confidentialité**. **Créer le compte** crée votre compte, avec son premier projet, Personal.

</Steps>

Chaque fois que quelqu’un se connecte à votre compte avec un code reçu par e-mail, tTerm vous écrit : **New sign-in to tTerm**, avec le navigateur, son adresse IP et l’heure. Pour l’instant, les e-mails de tTerm arrivent en anglais. Si ce n’était pas vous, appuyez sur **Oublier tous les appareils** dans Paramètres (**Open Settings**, dans l’e-mail, y mène), puis changez le mot de passe de votre messagerie : la personne qui s’est connectée a pu la lire.

## Le code court

Juste après le code, la page propose **Créez un code court pour cet appareil** : quatre chiffres, puis les quatre mêmes une seconde fois. Des chiffres tous identiques ou consécutifs sont refusés. La prochaine fois, ce navigateur ne demande que le code court.

Il ne fonctionne qu’avec une longue clé aléatoire que garde ce navigateur : il ne sert donc à rien sur un autre appareil. Cinq essais erronés font oublier l’appareil, et il faut de nouveau un code reçu par e-mail. **Code oublié ?** en envoie un tout de suite, après quoi la page propose un nouveau code court.

**Pas maintenant** continue sans code court : la prochaine fois, ce navigateur demande un code reçu par e-mail et propose de nouveau le code court.

Après 8 heures d’inactivité, la session prend fin, et la page vous demande de vous reconnecter : **Votre session a pris fin. Reconnectez-vous : vos terminaux ont continué de tourner.** Sur un appareil qui a un code court, le code court suffit.

## Se déconnecter

Le compte, en bas de la barre latérale, ouvre un menu avec **Paramètres**, **Langue**, **Compte** et **Se déconnecter**. **Se déconnecter** met fin à la session, et ce navigateur vous oublie : la prochaine fois, il demande un code reçu par e-mail, et non le code court. Les notes tapées ici et pas encore enregistrées sont perdues elles aussi. Vos terminaux continuent de tourner.

Pour changer de compte, déconnectez-vous et reconnectez-vous avec l’autre adresse e-mail. **Changer de compte**, sur l’écran du code court, demande aussi une adresse e-mail.

## Vos appareils

**Paramètres** → **Appareils** liste les navigateurs où vous vous connectez avec un code court, et chaque tTerm pour Mac connecté via le navigateur, nommés comme tTerm les voit : Chrome on macOS, tTerm for Mac on MacBook-Pro. Pour chacun, la liste indique quand il a été approuvé ou s’est connecté, et quand il a servi pour la dernière fois ; **Cet appareil** marque celui que vous utilisez.

- **Oublier** un navigateur : il faudra de nouveau un code reçu par e-mail pour s’y connecter. Oublier tTerm pour Mac : il est déconnecté et ne fonctionne plus qu’avec ce Mac, comme avant la connexion. Oublier l’appareil que vous utilisez : vous êtes déconnecté ici.
- **Oublier tous les appareils…**, puis **Oublier tous les appareils** : tous les appareils sont oubliés et toutes les sessions prennent fin, celle-ci comprise. Chaque navigateur demande ensuite un code reçu par e-mail. Vos terminaux continuent de tourner.

Un navigateur garde son code court 90 jours à partir du jour où vous l’avez créé : ensuite, il redemande un code reçu par e-mail et propose un nouveau code court. Un appareil qui ne s’est pas connecté depuis 90 jours est oublié automatiquement et disparaît de la liste.

## tTerm pour Mac

[tTerm pour Mac](../../local/mac/) se connecte via votre navigateur. Dans l’application, appuyez sur **Se connecter avec le navigateur** sur son premier écran, ou sur **Se connecter** dans le menu en bas de la barre latérale : elle ouvre app.tterm.net et affiche un code. Dans le navigateur, connectez-vous si ce n’est pas déjà fait, vérifiez que la page affiche le même code et appuyez sur **Autoriser**. Si vous vous êtes connecté dans ce navigateur il y a plus d’un quart d’heure, la page vous demande d’abord de confirmer que c’est bien vous, avec le code court ou un code reçu par e-mail.

Le Mac devient une machine dans Personal, l’application apparaît sous **Appareils**, et tTerm vous écrit au sujet de la nouvelle connexion, comme pour un navigateur.

Pour connecter l’application à un autre compte que celui de ce navigateur, appuyez sur **Ce n’est pas vous ? Utilisez un autre compte** sous **Annuler**. La session du navigateur prend fin, son code court reste, et la page demande d’abord l’autre adresse e-mail.

## Votre adresse e-mail et votre compte

Votre adresse e-mail figure sur la page **Compte**, dans le même menu. Pour la changer, écrivez à [support@tterm.net](mailto:support@tterm.net). Pour supprimer votre compte, écrivez à la même adresse depuis celle avec laquelle vous vous connectez.
