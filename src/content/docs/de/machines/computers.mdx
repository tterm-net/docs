Einem Computer genügt ein kleiner Agent. Er verbindet sich selbst mit der Cloud und hält diese eine Verbindung, deshalb sind keine eingehenden Ports nötig: Der Computer funktioniert auch hinter NAT.

:::tip[Auf einem Mac ist die App bequemer]
[Das lokale Terminal für Mac](../../local/mac/) hält die Verbindung zur Cloud, solange es läuft, und dieser Mac braucht keinen Agenten.
:::

## Verbinden

Öffne in tTerm Web **Maschine hinzufügen** und wähl **Computer**. Führ den Befehl in einem Terminal auf diesem Computer aus, als dein eigener Benutzer, nicht mit sudo:

```sh title="Auf dem Computer"
curl -fsSL https://connect.tterm.net/c/<token> | sh
```

Der Computer erscheint ein paar Sekunden nach dem Befehl im Projekt. Der Befehl funktioniert einmal, in den nächsten 10 Minuten.

## Was der Befehl macht

- Legt den Agenten in `~/.tterm-web` ab: eine Datei für dieses System aus unseren Releases, die vor dem Start gegen die Prüfsumme im Skript des Befehls geprüft wird.
- Erzeugt für diesen Computer einen eigenen Schlüssel und bewahrt ihn dort auf, lesbar nur für dich. Das Token im Befehl dient allein dem Beitritt, ein einziges Mal.
- Startet den Agenten bei jeder Anmeldung. Der Agent läuft als du, nie als root, und öffnet keine Ports.
- Der Agent aktualisiert sich selbst, nur auf Versionen, die unser Release-Build signiert hat, und nur solange auf dem Computer kein Terminal offen ist.

## Entfernen

Entferne den Computer auf der Seite des Projekts: Der Agent erfährt davon und stoppt ([mehr](../remove/#ein-computer)). Um den Agenten selbst vom Computer zu nehmen, führ aus:

```sh title="Auf dem Computer"
~/.tterm-web/uninstall.sh
```
