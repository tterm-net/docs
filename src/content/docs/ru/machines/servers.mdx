Сервер подключается по обычному SSH одной командой. Ключей не храним: на каждое подключение подписываем свой сертификат, который живёт две минуты и годится только для этого сервера.

## Подключить

<Steps>

1. В tTerm Web открой «Добавить машину» и выбери «Сервер».

2. Скопируй команду и выполни её на сервере от root или от любого пользователя с sudo:

   ```sh title="На сервере"
   curl -sSL https://connect.tterm.net/s/<токен> | sudo sh
   ```

3. Сервер появится в проекте, как только скрипт завершится, обычно в течение минуты. Облако само войдёт на него, проверит и прочитает, что это за машина: система, адрес, шелл.

</Steps>

:::caution[Команда одноразовая]
Она сработает один раз в течение 10 минут. Не успел – нажми «Получить новую команду».
:::

## Что делает скрипт

- Создаёт пользователя `tterm` без пароля. Если его уже создал наш бот в Telegram, использует его.
- Разрешает облаку входить как `tterm` по сертификатам, которые живут две минуты и выпускаются только для этого сервера. Ключей на сервере не остаётся.
- Даёт `tterm` права sudo, чтобы можно было управлять сервером. Забрать их можно одной командой.
- Не трогает `sshd_config` и не открывает портов. Запускать повторно безопасно.

Доверие – одна строка в `authorized_keys` пользователя `tterm`, и у каждого сервера она своя:

```text title="~tterm/.ssh/authorized_keys"
cert-authority,principals="m-…" ssh-ed25519 AAAAC3NzaC1lZDI1NTE5… tterm-web ca-…
```

:::tip[Сервер за NAT или без входящего SSH]
Облако входит на сервер по SSH, поэтому порт SSH должен быть доступен снаружи. Если это не так, поставь на сервер агента, как на [компьютер](../computers/): связь пойдёт изнутри.
:::

## Убрать сервер

На странице проекта нажми ⋯ у сервера и выбери «Удалить машину». Облако перестанет входить на сервер и уберёт свой доступ с него. Если сервер не ответит, следом появится команда, которая сделает это на нём. Подробно – в разделе [Убрать машину](../remove/).

Как убрать всё остальное, что поставил установщик, написано в начале самого скрипта.
