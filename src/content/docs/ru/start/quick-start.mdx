Пять минут: вход, первая машина и первая команда. Понадобятся браузер и сервер на Linux или компьютер, на котором можно выполнить команду в терминале.

<Steps>

1. **Войди.** Открой [app.tterm.net](https://app.tterm.net) и введи почту: придёт письмо с кодом. В первый раз попросим назвать себя и придумать быстрый код из четырёх цифр для этого браузера.

   <Screenshot name="signin-email" alt="Вход в новом браузере: «Войти», введена почта anna@example.com, кнопка «Получить код»." />

2. **Добавь машину.** В боковой панели нажми **+** у раздела «Машины» и выбери «Сервер» или «Компьютер». Появится команда:

   ```sh title="На сервере, от root или пользователя с sudo"
   curl -sSL https://connect.tterm.net/s/<токен> | sudo sh
   ```

   Она сработает один раз в течение 10 минут. Сервер появится в проекте, как только скрипт завершится, обычно в течение минуты.

   <Screenshot name="add-server" alt="Окно «Добавить машину», выбран «Сервер»: одноразовая команда для сервера с кнопкой «Копировать», а tTerm Web ждёт сервер." />

3. **Открой терминал.** Нажми **+** рядом с машиной в боковой панели. Терминал откроется во вкладке: твой шелл, твои программы, sudo.

4. **Набери команду.** Например, `uptime`. Команда придёт блоком: вывод, код возврата, время, папка и ветка. Вкладку можно закрыть: терминал работает дальше.

</Steps>

:::note[Компьютер вместо сервера]
Для компьютера команда другая, и её выполняют без sudo: подробно в разделе [Компьютер](../../machines/computers/).
:::

:::tip[Серверы с твоего Mac – сразу]
Серверы, на которые твой Mac ходит по SSH, переносятся все сразу, вместе с ключами, и на них ничего не нужно запускать: подробно в разделе [Перенести в облако](../../local/move-to-cloud/).
:::
