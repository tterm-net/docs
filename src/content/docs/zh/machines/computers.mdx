电脑只需要一个小型代理。它会自己连接云端，并只保持这一条连接，因此不需要任何入站端口：电脑位于 NAT 之后也能用。

:::tip[在 Mac 上，用应用更方便]
[Mac 上的本地终端](../../local/mac/)在运行期间会一直与云端保持连接，这台 Mac 就不需要代理了。
:::

## 连接电脑

在 tTerm Web 中打开**添加机器**，选择**电脑**。在那台电脑的终端中，以你自己的身份运行命令，不要用 sudo：

```sh title="在电脑上"
curl -fsSL https://connect.tterm.net/c/<token> | sh
```

命令完成几秒钟后，电脑就会出现在项目中。命令只能使用一次，在接下来的 10 分钟内有效。

有了 [SSH 密钥保险库](../../security/keys/)之后，电脑只在密钥已打开的设备上才能打开：在其他设备上，它的 **+** 会换成锁形图标。参见[密钥已打开的地方](../../security/keys/#密钥已打开的地方)。

## 这条命令会做什么

- 把代理放到 `~/.tterm-web`：这是我们发布版本中适用于这个系统的单个文件，运行前会用命令脚本中的校验和进行核对。
- 为这台电脑生成专属密钥并保存在本机，只有你能读取。命令中的令牌只用于让它加入，且只能用一次。
- 每次你登录时启动代理。代理以你的身份运行，绝不以 root 身份运行，也不开放任何端口。
- 代理会自行更新，只会更新到由我们的发布构建签名的版本，而且只在这台电脑上没有打开的终端时进行。

## 移除电脑

在项目页面上移除这台电脑：代理得知后就会停止运行（[详情](../remove/#电脑)）。要从电脑上卸载代理本身，运行：

```sh title="在电脑上"
~/.tterm-web/uninstall.sh
```
