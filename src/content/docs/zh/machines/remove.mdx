移除一台机器，它就会从 tTerm Web 中消失，tTerm 对它的访问权限也随之收回。机器所在项目的所有者和管理员都可以这样做。

## 如何移除

可以在两个地方移除：

- 在**机器**页面上（点击侧边栏顶部的 tTerm 标志即可打开），点击机器卡片上的**移除**。
- 在项目页面上（点击侧边栏中的项目名称即可打开），点击机器旁的 **⋯**，然后选择**移除机器**。

tTerm 会先询问，并说明会发生什么：**移除 web-01？** 点击红色的**移除 web-01** 即可移除，点击**取消**则一切保持原样。

有了保险库之后，电脑、用你的密钥打开的服务器和通过你的 Mac 打开的服务器，都只能在密钥已打开的地方移除。在其他设备上，窗口会显示 **web-01 在这台设备上已关闭：只有在密钥已打开的地方才能移除。请在这里打开密钥。** 它会就在窗口中打开你的密钥，就像[密钥已打开的地方](../../security/keys/#密钥已打开的地方)中那样；密钥打开后，才会出现红色的**移除 web-01**。

## 会发生什么

- 机器的终端会结束，每个终端都会说明原因：**这个终端已结束**，**web-01 已从 tTerm Web 中移除。**
- 机器会从侧边栏、**机器**页面和项目页面中消失，它的日志也会从项目的**日志**文件夹中消失。
- 在那里输入过的命令会保留在你的历史记录中：[搜索](../../features/search/)仍然能找到它们，并注明机器已被移除。项目的操作日志中会留下一条关于这次移除的记录。

## 服务器

云端会停止登录这台服务器，并直接在服务器上把自己的那一行从 `~tterm/.ssh/authorized_keys` 中删掉。随后页面会显示：**web-01 已从 tTerm Web 中移除，tTerm Web 在这台服务器上的访问权限也已收回。**

如果服务器没有响应，这一行就会留在那里，不过云端已经不再登录。这时会出现一个窗口，给出删除这一行的命令。关闭窗口之前先复制它，然后在服务器上运行：

```sh title="在服务器上"
sudo sed -i '/^cert-authority,principals="m-…" /d' ~tterm/.ssh/authorized_keys
```

窗口中的命令通过 `principals="m-…"` 指明这台服务器自己的那一行，文件中的其他行都保持不变。同一台服务器如果也在另一个项目中，它在那里是一台独立的机器，有自己的一行，会继续正常工作。

用户 `tterm` 及其 sudo 规则 `/etc/sudoers.d/tterm` 在移除后仍会保留：tTerm 机器人可能还要用到它们。把它们也删掉的命令写在安装脚本的开头，没有响应的服务器的窗口中也有：

```sh title="在服务器上"
sudo userdel -r tterm && sudo rm -f /etc/sudoers.d/tterm
```

删掉它们之后，tTerm 机器人的访问权限，以及这台服务器在你其他项目中的访问权限，也会随之失去。

### 从 Mac 迁移来的服务器

用**我的密钥**或**通过这台 Mac** 从 [tTerm Mac 版](../../local/move-to-cloud/)迁移来的服务器上没有任何 tTerm 的东西，所以也没有什么要删除的。如果用的是 **tTerm 通行证**，tTerm 的那一行位于 Mac 登录时所用用户的 `~/.ssh/authorized_keys` 中，云端会用同样的方式把它删掉。如果这样的服务器没有响应，请自己到服务器上删掉这一行：它以 `cert-authority,principals="m-…"` 开头。

## 电脑

电脑上的代理会立即得知电脑已被移除，随即丢弃自己的密钥并停止运行。这个密钥再也无法使用，所以即使密钥泄露了，只要移除它所属的电脑，它就失效了。处于休眠或离线状态的电脑，会在代理下次连接时得知这一消息。

如需重新连接这台电脑：点击**添加机器**，然后选择**电脑**。安装程序会为它生成新的密钥，它会作为一台新机器重新出现。

代理本身会留在电脑上，直到你把它卸载：

```sh title="在电脑上"
~/.tterm-web/uninstall.sh
```

这个脚本会删除代理的自动启动项、整个 `~/.tterm-web`（包括电脑的密钥），以及 tTerm 的终端放在 `~/.tterm` 中的 shell 脚本。同样位于 `~/.tterm` 中的 tTerm 机器人的代理会保留。单靠这个脚本并不会把电脑从 tTerm Web 中移除：在你移除它之前，它会一直留在列表中。

## 装有 tTerm Mac 版的 Mac

登录后，[tTerm Mac 版](../../local/mac/)会取代代理，自己维持这台 Mac 与 tTerm Web 之间的连接。为此，它在**设置** → **这台电脑**中提供了一个开关：**向 tTerm Web 和手机开放**。打开时，只要 tTerm 在这台 Mac 上运行，tTerm Web 和你的手机就能打开它上面的终端：有了保险库之后，只能在密钥已打开的地方打开（[详情](../../security/keys/#密钥已打开的地方)）。关闭时，这台 Mac 在 tTerm Web 中显示为离线，而在应用中一切照旧；从 tTerm Web 在这台 Mac 上打开的终端会结束，结束前会先询问。

在 tTerm Web 中移除 Mac，和移除任何电脑一样。之后**这台电脑**中会显示：**这台 Mac 已从 tTerm Web 中移除，因此不再向 tTerm Web 开放。打开上方的开关即可重新添加。**

这个应用同时也是你的设备之一：在**设置** → **设备**中点击**移除**，它就会退出登录，此后只能用于这台 Mac 本身。详见[设备与登录](../../account/devices/)。

:::note[结束终端不等于移除机器]
从侧边栏或搜索中结束一个终端，只会结束这一个 shell，结束前会先询问。机器会保留，它的其他终端也一样。
:::
