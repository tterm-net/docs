title: 笔记

笔记放在项目的文件夹里，就像终端运行在项目的机器上：运维手册、访问说明、检查清单，都和它们所涉及的机器放在一起。一篇笔记由标题和若干块组成，直接在原处编写，并会自动保存。

## 文件夹

在侧边栏中，每个项目的机器下方都有**笔记**。点击**笔记**旁的 **+** 可以新建文件夹：为它命名，然后点击**创建文件夹**。点击文件夹旁的 **+** 会在其中新建一篇笔记，并在单独的标签页中打开；点击文件夹本身只会将它折叠或展开。项目页面上也有相同功能的按钮：**新建文件夹**，以及每个文件夹上的**新建笔记**。

项目页面上文件夹旁的 **⋯** 中有**重命名文件夹**和**删除文件夹**。文件夹会连同其中的笔记一起删除：窗口会列出这些笔记，所以想保留的笔记请先移出去。

目前每个项目里都只有你一个人，所以项目的笔记只有你能看到，其中所有的笔记和文件夹也都由你来编写、移动和删除。笔记标题下方也是这么写的：**仅你可见**。

## 编写

新笔记打开时，光标位于标题中，按 **Enter** 进入正文。正文由块组成：文本、标题、列表项、检查项、代码和分隔线。按 **Enter** 开始一个新块；在空的列表项上按下，则会结束列表。

在块的开头输入 Markdown 标记，块就会变成相应的类型：

| 在块的开头输入 | 会变成 |
| --- | --- |
| `#` 和空格 | 标题 |
| `-` 和空格，或 `1.` 和空格 | 列表项 |
| `- [ ]` 和空格 | 检查项，`- [x]` 则是已勾选的检查项 |
| `` ``` `` | 代码 |
| `---` | 分隔线 |

在块的其他位置，Markdown 会保持原样。在空行中输入 **/**，会以列表形式提供同样的选项：**检查清单**、**标题**、**列表**、**代码**、**分隔线**、**文本**。之后输入的字母会筛选列表，方向键用于移动，按 **Enter** 选定。粘贴的多行文本会变成块，其中的 Markdown 也会按同样的方式识别。

## 代码与检查清单

代码块会保留换行：在其中按 **Enter** 会换行，按 **Tab** 会插入两个空格，在 Mac 上按 **⌘Enter**（在其他系统上按 **Ctrl+Enter**）则会离开代码块，在下方开始一个新块。粘贴进去的文本会保持原样。代码块角落的**复制**会复制代码，并短暂显示**已复制**。

点击检查项的方框即可勾选它。勾选会立即保存，检查项旁边会显示是谁在什么时候勾选的：当天的显示为**你 · 10:02**，更早的则显示日期。侧边栏会显示检查清单的进度，如 2/5，项目页面上则显示**已完成 2/5**。

## 保存

停止输入片刻后，笔记会自动保存。标签页右侧会显示保存状态：**正在保存…**、**已保存**或**未保存：无连接**。

在两台设备上同时编辑同一篇笔记，双方的修改都会保留：每次保存都会与在此期间保存的内容逐块合并。只有当同一个块或标题在两边都被修改时，笔记才会询问那里要保留哪个版本：**保留我的**或**保留另一个版本**；其余内容会保留双方的修改。为了合并，tTerm 会保留每篇笔记最近的 50 个版本。

没有网络连接时，你输入的内容会暂存在这个浏览器中，直到保存成功，页面也会不断重试。即使关闭标签页或刷新页面，再次打开这篇笔记时，这些内容也会恢复：**已恢复这篇笔记中输入但未保存的内容。**

:::caution[退出登录会丢弃未保存的内容]
点击**退出登录**后，这个浏览器会丢弃笔记中已输入但尚未保存的内容。
:::

## 移动、复制或删除

其余操作都在笔记旁的 **⋯** 中，它位于项目页面上或笔记标签页的顶部：

- **文件夹**：项目中的文件夹，笔记当前所在的文件夹带有勾选标记；点击另一个文件夹即可把笔记移过去。项目中有两个文件夹后才会出现这一项。
- **移到其他项目…**：窗口会列出你的其他项目及其文件夹，选择一个文件夹，然后点击相应的按钮，例如**移到 运维手册**。没有文件夹的项目会提供一个新文件夹，名称与笔记原来所在的文件夹相同。笔记的标题、正文和历史记录会一起移过去，勾选记录及勾选人也会保留。
- **复制为 Markdown**：复制整篇笔记，笔记标题作为一级标题。
- **删除笔记**：会先询问。删除的笔记无法恢复。

搜索也能找到笔记：以 `n:` 开头，详见[搜索](../search/)。

## 日志

在侧边栏中，**日志**排在项目所有文件夹的最前面，并标有**由 tTerm 记录**。其中为项目的每台机器各存一份日志：通过 tTerm 在这台机器上运行的每条命令，按天排列，命令下方还有添加的笔记。日志由 tTerm 写入，任何人都无法更改。日志中的各行保留一年，命令的输出保留 30 天。详见[机器的日志](../log/)。
