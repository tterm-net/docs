只需五分钟：登录，添加第一台机器，运行第一条命令。你需要一个浏览器，以及一台 Linux 服务器，或者一台能在终端里运行命令的电脑。

<Steps>

1. **登录。** 打开 [app.tterm.net](https://app.tterm.net)，输入你的邮箱：验证码会通过邮件发给你。第一次登录时，我们会请你填写名字，并为这个浏览器设置一个四位数的快捷码。

   <Screenshot name="signin-email" alt="在新浏览器中登录：“登录”，已输入邮箱 anna@example.com，以及“获取验证码”。" />

2. **添加机器。** 在侧边栏中，点击**机器**旁边的 **+**，然后选择**服务器**或**电脑**。随后会出现一条命令：

   ```sh title="在服务器上，以 root 或有 sudo 权限的用户身份运行"
   curl -sSL https://connect.tterm.net/s/<token> | sudo sh
   ```

   命令只能使用一次，在接下来的 10 分钟内有效。脚本一完成，服务器就会出现在项目中，通常不超过一分钟。

   <Screenshot name="add-server" alt="“添加机器”窗口，已选择“服务器”：要在服务器上运行的一次性命令，带有“复制”按钮，tTerm Web 正在等待服务器。" />

3. **打开终端。** 点击侧边栏中机器旁边的 **+**。终端会在标签页中打开：你的 shell、你的程序、sudo。

4. **输入命令。** 比如 `uptime`。结果会以块的形式返回：输出、退出码、时间、目录和分支。标签页可以关掉：终端会继续运行。

</Steps>

:::note[电脑而非服务器]
电脑有自己的命令，而且运行时不用 sudo：详见 [macOS 或 Linux 电脑](../../machines/computers/)。
:::

:::tip[一次迁入你的 Mac 上的服务器]
你的 Mac 能通过 SSH 连接的服务器，可以连同密钥一次全部迁移过来，不需要在服务器上运行任何东西：详见[迁移到云端](../../local/move-to-cloud/)。
:::
