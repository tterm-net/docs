Windows 上的本地终端正在开发中。推出时，我们会在 [Telegram 频道](https://t.me/tTermBlog)和[博客](https://tterm.net/zh/blog/)上公布。

## 目前

- **云终端**可以在 Windows 的任何浏览器中使用：打开 [app.tterm.net](https://app.tterm.net)，你所有的服务器和电脑就都在手边。
- 暂时还不能把 Windows 电脑添加为机器。Linux 服务器以及 macOS 或 Linux 电脑可以，详见[服务器](../../machines/servers/)和[电脑](../../machines/computers/)。
