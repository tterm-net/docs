Linux 上的本地终端正在开发中。推出时，我们会在 [Telegram 频道](https://t.me/tTermBlog)和[博客](https://tterm.net/zh/blog/)上公布。

## 目前

- **Linux 电脑**可以接入云端：用一条命令装上小型代理，就能在任何浏览器中打开这台电脑的终端。详见 [macOS 或 Linux 电脑](../../machines/computers/)。
- **云终端**可以在 Linux 的任何浏览器中使用，地址是 [app.tterm.net](https://app.tterm.net)。
