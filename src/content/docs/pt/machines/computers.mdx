Um computador só precisa de um pequeno agente. Ele se conecta à nuvem sozinho e mantém essa única conexão, então não precisa de portas de entrada: o computador funciona até atrás de NAT.

:::tip[No Mac, o app é mais fácil]
[O terminal local para Mac](../../local/mac/) mantém a conexão com a nuvem enquanto está rodando, e esse Mac não precisa de agente.
:::

## Conectar

No tTerm Web, abra **Adicionar uma máquina** e escolha **Computador**. Execute o comando num terminal desse computador, com o seu próprio usuário, sem sudo:

```sh title="No computador"
curl -fsSL https://connect.tterm.net/c/<token> | sh
```

O computador aparece no projeto alguns segundos depois que o comando terminar. O comando funciona uma vez, nos próximos 10 minutos.

<Screenshot name="add-computer" alt="A janela “Adicionar uma máquina”, com “Computador” selecionado: o comando para executar no computador com o seu próprio usuário, o botão “Copiar” e o tTerm Web aguardando o agente." />

Se você tiver um [cofre de chaves SSH](../../security/keys/), um computador só abre num dispositivo em que as chaves estão abertas: nos outros, ele tem um cadeado no lugar do **+**. Veja [Onde as chaves estão abertas](../../security/keys/#onde-as-chaves-estão-abertas).

## O que o comando faz

- Coloca o agente em `~/.tterm-web`: um único arquivo para este sistema, das nossas versões publicadas, conferido com o checksum do script do comando antes de rodar.
- Cria uma chave própria para este computador e a guarda nele, legível só por você. O token do comando só serve para conectá-lo, uma única vez.
- Inicia o agente sempre que você entra no sistema. O agente roda como você, nunca como root, e não abre portas.
- O agente se atualiza sozinho, só para versões assinadas pelo nosso build de release, e só enquanto nenhum terminal estiver aberto no computador.

## Remover

Remova o computador na página do projeto: o agente fica sabendo e para ([mais](../remove/#computador)). Para tirar o próprio agente do computador, execute:

```sh title="No computador"
~/.tterm-web/uninstall.sh
```
