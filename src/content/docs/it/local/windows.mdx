Il terminale locale per Windows è in lavorazione. Quando uscirà, lo annunceremo sul nostro [canale](https://t.me/tTermBlog) e sul [blog](https://tterm.net/it/blog/).

## Già oggi

- **Il terminale cloud** funziona in qualsiasi browser su Windows: apri [app.tterm.net](https://app.tterm.net), e hai a portata di mano tutti i tuoi server e computer.
- Un computer Windows non si può ancora aggiungere come macchina. I server Linux e i computer con macOS o Linux sì: un [server](../../machines/servers/), un [computer](../../machines/computers/).
