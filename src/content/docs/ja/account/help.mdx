サイドバーの下のアカウントを押すとメニューが開き、その中の **ヘルプ** には次の項目があります。

- **ドキュメント** を押すと、このドキュメントが tTerm と同じ言語で開きます。
- **サポートに問い合わせる** を押すと、tTerm へのメッセージを書くウィンドウが開きます。

## サポートに問い合わせる

**何が起きたか** の欄に起きたことを自分の言葉で書き、**送信** または **⌘Enter**（Windows と Linux では **Ctrl+Enter**）を押します。返信はアカウントのメールアドレスに届きます。メッセージの控えもすぐにそこへ届くので、送った内容は手元にも残ります。

**技術情報を添付する** には、最初からチェックが入っています。このとき、メッセージには 1 行の情報が添えられ、その行は送られるとおりの形でチェックボックスのすぐ下に表示されます。内容は tTerm Web のバージョン、ブラウザーとそれが動くシステム、プラン、マシンの台数で、たとえば **tTerm Web 0.1.28 · Chrome 141, macOS · Free プラン · マシン 3 台** のようになります。コマンドやその出力、ノートが含まれることはありません。メッセージだけを送るには、チェックを外します。

送信すると **送信しました** と表示され、返信がどこに届くかが示されます。

サインインする前の Mac 版 tTerm では、ウィンドウで **メールアドレス** の入力を求められ、返信はそのアドレスに届きます。このアドレスは確認されていないため、控えは送られません。

メッセージは 1 時間に 5 通まで送れます。サインイン前は、1 つのネットワークから 1 時間に 3 通までです。メッセージが送れなかったときはウィンドウにそう表示され、自分でメールを送るための宛先 [support@tterm.net](mailto:support@tterm.net) が示されます。

## tTerm について

同じメニューの **tTerm について** からは、**tterm.net サイト**、tTerm の **Telegram チャンネル**、[**最新情報**](../../whats-new/web/) を開けます。最新情報には、tTerm Web の各バージョンでの変更点が、アプリでは Mac 版 tTerm の各バージョンでの変更点が載っています。
