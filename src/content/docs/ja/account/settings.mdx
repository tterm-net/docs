サイドバーの下のアカウントメニューにある **設定** を押すと、今いるページの上にウィンドウが開きます。下のページはそのままです。左側には検索と、グループごとに並んだセクションがあり、右側には選んだセクションが行ごとに表示されます。各行の左側には項目名が、右側には値やボタンがあります。×、**Esc**、またはウィンドウの外側のクリックでウィンドウが閉じ、元の場所に戻ります。

- **環境設定**：**一般**、**アカウント**、**プラン**。
- **セキュリティ**：**SSH 鍵** と **デバイス**。
- **Mac 版 tTerm**（アプリ内）：**このコンピューター** と **アップデート**。

アカウントメニューのいちばん上にある名前とメールアドレスを押すと、**設定** → **アカウント** が開きます。各セクションには app.tterm.net/settings/devices のような専用のアドレスがあるので、新しいサインインを知らせるメールからは **デバイス** が直接開きます。スマートフォンでは、設定は画面全体に表示されます。まずセクションの一覧が、次にタップしたセクションが表示され、矢印で一覧に戻れます。

サインインする前の Mac 版 tTerm では、設定にあるのは **一般** と **アップデート** だけで、そこで選んだ内容はこのコンピューターに保存されます。

## 検索

セクションの上にある **検索** は、入力した語をすべて含むセクションだけを残し、該当する行を強調表示します。たとえば `色` と入力すると **一般** が残り、**プロジェクトの色** が強調表示されます。大文字と小文字、アクセント記号の有無は区別されません。**Esc** を押すと、まず検索がクリアされ、次にウィンドウが閉じます。

<Screenshot name="settings-search" alt="「設定」の「検索」にテーマと入力した状態：左側には「一般」だけが残り、右側ではその「テーマ」の行がハイライトされています。" />

## 一般

- **外観**：**テーマ** は **システム**、**ライト**、**ダーク** から、**プロジェクトの色** は **コードバッジ** か **プロジェクト全体** から選べます。詳しくは[色](../../features/projects/#色)をご覧ください。どちらもアカウントに保存され、すべてのデバイスで使われます。
- **言語**：**表示言語** です。アカウントメニューの **言語** でも同じように選べます。

## アカウント

- **写真**：**写真を追加**、または **写真を変更** と **写真を削除**。5 MB までの JPEG、PNG、WebP を選び、**写真** ウィンドウで円の中の位置を合わせて **写真を保存** を押します。写真は名前の横に、イニシャルの代わりに表示されます。tTerm は 256 ピクセルのコピーを保存し、撮影場所など写真自体に含まれる情報は残しません。
- **名前**：**名前を編集** を押し、新しい名前を入力して **保存** を押します。
- **メールアドレス**：サインインに使うアドレスです。変更するには、[support@tterm.net](mailto:support@tterm.net) までご連絡ください。

**アカウントの削除**：アカウントを削除するには、サインインに使っているメールアドレスから support@tterm.net までご連絡ください。**アカウントを削除** の横にある **サポートに問い合わせる** を押すと、そのためのウィンドウが開きます。[サポートに問い合わせる](../help/#サポートに問い合わせる)と同じウィンドウで、返信はアカウントのメールアドレスに届きます。

## プラン

あなたのプラン **Free** と **上限：マシン 50 台、同時に開けるターミナル 24 個**、そして現在の使用量を示す 2 つのメーター、**マシン** と **開いているターミナル** が表示されます。その下に薄く表示されている **お支払い** には、有料プランの開始とともに **支払い方法と請求書** が表示されます。詳しくは[プランと上限](../plan/)をご覧ください。

## SSH 鍵

[SSH 鍵の保管庫](../../security/keys/#設定--ssh-鍵)について、ここで開いているかどうか、保管庫のパスワード、保存した鍵、パスワードなしで保管庫を開ける場所が表示されます。

## デバイス

クイックコードでサインインするブラウザーと、ブラウザー経由でサインインした Mac 版 tTerm が表示されます。どれかを **登録解除** するか、**すべてのデバイスの登録を解除…** を押します。詳しくは[あなたのデバイス](../devices/#あなたのデバイス)をご覧ください。

## このコンピューター

Mac 版 tTerm で、サインインしたあとに表示されます。**tTerm Web とスマートフォンから開けるようにする** のスイッチと、この Mac と tTerm Web のつながりの状態があります。詳しくは [Mac 版 tTerm を入れた Mac](../../machines/remove/#mac-版-tterm-を入れた-mac) をご覧ください。

## アップデート

Mac 版 tTerm にあります。**自動でアップデート** か **先に確認する** を選べ、**今すぐ確認** もあります。tTerm のメニューの **アップデートを確認…** からも、このセクションが開きます。詳しくは、Mac 版のページの[アップデート](../../local/mac/#アップデート)をご覧ください。
