5 分でできること。サインイン、最初のマシン、最初のコマンドです。ブラウザーと、Linux サーバーか、ターミナルでコマンドを実行できるコンピューターが必要です。

<Steps>

1. **サインインします。** [app.tterm.net](https://app.tterm.net) を開いてメールアドレスを入力すると、コードがメールで届きます。初回は、お名前と、このブラウザー用の 4 桁のクイックコードをお聞きします。

   <Screenshot name="signin-email" alt="新しいブラウザーからのサインイン：「サインイン」の画面にメールアドレス anna@example.com が入力され、「コードを受け取る」があります。" />

2. **マシンを追加します。** サイドバーの **マシン** の横にある **+** を押して、**サーバー** か **コンピューター** を選びます。コマンドが表示されます。

   ```sh title="サーバー上で、root または sudo が使えるユーザーとして"
   curl -sSL https://connect.tterm.net/s/<token> | sudo sh
   ```

   このコマンドは 1 回だけ、これから 10 分間だけ使えます。スクリプトが終わればすぐにサーバーがプロジェクトに現れます。通常は 1 分ほどです。

   <Screenshot name="add-server" alt="「マシンを追加」ウィンドウで「サーバー」を選んだ状態：サーバーで実行する 1 回限りのコマンドと「コピー」ボタンがあり、tTerm Web がサーバーを待っています。" />

3. **ターミナルを開きます。** サイドバーでマシンの横の **+** を押します。ターミナルがタブで開きます。いつものシェル、いつものプログラム、そして sudo です。

4. **コマンドを入力します。** たとえば `uptime`。結果はブロックになって返ってきます。出力、終了コード、時刻、フォルダー、ブランチです。タブは閉じてかまいません。ターミナルは動き続けます。

</Steps>

:::note[サーバーではなくコンピューターのとき]
コンピューターには別のコマンドがあり、sudo なしで実行します。詳しくは[コンピューター](../../machines/computers/)をご覧ください。
:::
