tTerm は、あなたのサーバーとコンピューターのためのクラウドターミナルです。マシンはあなたのもののまま、ターミナル、コマンドの履歴、ノートはクラウドにあります。ビルドの途中でノートパソコンを閉じ、スマートフォンから開けば、ビルドはそのまま進んでいます。デバイスに鍵を置く必要も、ポートを開ける必要もありません。

## どこで作業するか

- **クラウドターミナル、tTerm Web** – ブラウザーで [app.tterm.net](https://app.tterm.net) を開きます。ノートパソコン、タブレット、スマートフォンから、すべてのマシン、ターミナル、ノートを扱えます。
- **ローカルターミナル** – Mac 用のアプリです。このコンピューターのシェルとクラウド全体が 1 つのウィンドウに入ります。アカウントなしでも使えます。[Mac 版](../../local/mac/)はこちら。Windows 版と Linux 版は開発中です。
- **Telegram のボット** – チャットの中でそのまま使えるターミナル、[@tTermNetBot](https://t.me/tTermNetBot)。今のところウェブとは別に動いています。

## 基本の考え方

- **プロジェクト** – マシンとノートをまとめる場所です。Personal プロジェクトは誰にでもあり、その隣に自分のプロジェクトを作れます。どれにもコードと色があります。
- **マシン** – SSH で接続した Linux サーバー、または小さなエージェントを入れた macOS か Linux のコンピューターです。
- **ターミナル** – マシン上の本物のシェルです。そのマシンの設定どおり、bash か zsh が動きます。ターミナルはタブではなくクラウドにあるので、タブを閉じてもターミナルは動き続けます。
- **ブロック** – 1 つのコマンドと、その出力、終了コード、時刻、フォルダー、git のブランチをまとめたものです。ブロックはコピーも、再実行も、検索で見つけることも簡単です。
- **ノート** – プロジェクトのフォルダーに置く Markdown です。チェックリスト、コマンド、手順書を、関係するマシンのそばに置けます。

:::tip[ベータ期間は無料]
今あるものはすべて無料で使えます。マシンは 50 台まで、同時に開けるターミナルは 24 個までです。有料プランは後から登場します。その際は前もってお知らせします。
:::
