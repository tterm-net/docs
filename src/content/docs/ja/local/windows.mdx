Windows 版のローカルターミナルは開発中です。公開したら、[チャンネル](https://t.me/tTermBlog)と[ブログ](https://tterm.net/ja/blog/)でお知らせします。

## 今できること

- **クラウドターミナル** は Windows のどのブラウザーでも使えます。[app.tterm.net](https://app.tterm.net) を開けば、サーバーとコンピューターがすべて手元にそろいます。
- Windows のコンピューター自体をマシンとして追加することは、まだできません。Linux サーバーと、macOS または Linux のコンピューターなら追加できます。[サーバー](../../machines/servers/)、[コンピューター](../../machines/computers/)をご覧ください。
