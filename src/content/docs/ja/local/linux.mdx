Linux 版のローカルターミナルは開発中です。公開したら、[チャンネル](https://t.me/tTermBlog)と[ブログ](https://tterm.net/ja/blog/)でお知らせします。

## 今できること

- **Linux のコンピューター** はクラウドに接続できます。小さなエージェントをコマンド 1 つで入れると、そのコンピューターのターミナルがどのブラウザーからでも開きます。詳しくは[コンピューター](../../machines/computers/)をご覧ください。
- **クラウドターミナル** は Linux のどのブラウザーでも、[app.tterm.net](https://app.tterm.net) で使えます。
