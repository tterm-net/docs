マシンを削除すると、マシンは tTerm Web から消え、tTerm のそのマシンへのアクセス権もなくなります。削除できるのは、マシンがあるプロジェクトのオーナーと管理者です。

## 削除する

削除できる場所は 2 つあります。

- **マシン** ページ（サイドバーのいちばん上にある tTerm のロゴで開きます）で、マシンのカードの **削除** を押します。
- プロジェクトのページ（サイドバーでプロジェクトの名前をクリックすると開きます）で、マシンの横の **⋯** を押し、**マシンを削除** を選びます。

tTerm は先に **web-01 を削除しますか？** と尋ね、何が起こるかを示します。赤い **web-01 を削除** を押すと削除され、**キャンセル** を押すと何も変わりません。

## 削除するとどうなるか

- マシンのターミナルは終了し、それぞれに理由が表示されます：**このターミナルは終了しました**、**web-01 は tTerm Web から削除されました。**
- マシンはサイドバー、**マシン** ページ、プロジェクトのページから消え、マシンのログもプロジェクトの **ログ** からなくなります。
- そこで入力したコマンドは履歴に残ります。[検索](../../features/search/)でも引き続き見つかり、マシンが削除されたことも表示されます。プロジェクトのログには、削除したことが記録されます。

## サーバー

クラウドはサーバーへのサインインをやめ、サーバー上の `~tterm/.ssh/authorized_keys` から自身の行を取り除きます。ページには次のように表示されます：**web-01 を tTerm Web から削除し、サーバー上の tTerm Web のアクセス権も取り消しました。**

サーバーが応答しない場合、クラウドはもうサインインしませんが、行はサーバーに残ります。そのときは、この行を取り除くコマンドがウィンドウに表示されます。ウィンドウを閉じる前にコピーして、サーバー上で実行してください。

```sh title="サーバー上で"
sudo sed -i '/^cert-authority,principals="m-…" /d' ~tterm/.ssh/authorized_keys
```

ウィンドウのコマンドは、`principals="m-…"` でこのサーバー自身の行だけを指定し、ファイルのほかの行には触れません。同じサーバーが別のプロジェクトにもある場合、そちらは独自の行を持つ別のマシンなので、そのまま使えます。

ユーザー `tterm` とその sudo のルール `/etc/sudoers.d/tterm` は、削除したあとも残ります。tTerm のボットが使っていることがあるためです。これらも削除するコマンドは、インストーラーのスクリプトの冒頭と、応答しなかったサーバーのウィンドウにあります。

```sh title="サーバー上で"
sudo userdel -r tterm && sudo rm -f /etc/sudoers.d/tterm
```

これらを削除すると、tTerm のボットのアクセス権と、ほかのプロジェクトにあるこのサーバーのアクセス権もなくなります。

### Mac から移行したサーバー

[Mac 版 tTerm](../../local/move-to-cloud/) から **自分の鍵** か **この Mac 経由** で移行したサーバーには、tTerm のものは何も置かれていないので、取り除くものもありません。**tTerm のアクセス権** の場合は、Mac がサインインしたユーザーの `~/.ssh/authorized_keys` に tTerm の行があり、クラウドが同じように取り除きます。そうしたサーバーが応答しない場合は、その行をサーバー上で自分で削除してください。行は `cert-authority,principals="m-…"` で始まります。

## コンピューター

エージェントはコンピューターが削除されたことをすぐに知り、鍵を破棄して停止します。その鍵は二度と使えないので、漏れた鍵も、そのコンピューターを削除すれば無効になります。スリープ中やオフラインだったコンピューターは、次にエージェントが接続したときに削除を知ります。

コンピューターをもう一度接続するには、**マシンを追加** から **コンピューター** を選びます。インストーラーが新しい鍵を作り、コンピューターは新しいマシンとして戻ります。

エージェント自体は、取り除くまでコンピューターに残ります。

```sh title="コンピューター上で"
~/.tterm-web/uninstall.sh
```

このスクリプトは、エージェントの自動起動と、コンピューターの鍵を含む `~/.tterm-web` 全体、それに tTerm のターミナルが `~/.tterm` に置いたシェルスクリプトを削除します。同じく `~/.tterm` にある tTerm のボットのエージェントは残ります。スクリプトだけでは、コンピューターは tTerm Web から削除されません。tTerm Web で削除するまで、一覧に残ります。

## Mac 版 tTerm を入れた Mac

サインインした [Mac 版 tTerm](../../local/mac/) は、エージェントの代わりに、Mac と tTerm Web のつながりを自分で保ちます。そのためのスイッチが、**設定** → **このコンピューター** にある **tTerm Web とスマートフォンから開けるようにする** です。オンにすると、tTerm がこの Mac で動いているあいだ、tTerm Web やスマートフォンからこの Mac のターミナルを開けます。オフにすると、tTerm Web ではこの Mac がオフラインになり、アプリではすべてこれまでどおりに使えます。tTerm Web からこの Mac で開いていたターミナルは、確認のあとで終了します。

Mac も、ほかのコンピューターと同じように tTerm Web で削除できます。削除すると、**このコンピューター** に次のように表示されます：**この Mac は tTerm Web から削除されたため、tTerm Web からは開けません。もう一度追加するには、これをオンにしてください。**

アプリは、あなたのデバイスの 1 つでもあります。**設定** → **デバイス** で **登録解除** を押すとアプリはサインアウトし、この Mac だけで使えるようになります。詳しくは[デバイスとサインイン](../../account/devices/)をご覧ください。

:::note[ターミナルの終了はマシンの削除ではありません]
サイドバーや検索からターミナルを終了すると、確認のあとで、そのシェルだけが終了します。マシンは残り、そのほかのターミナルもそのままです。
:::
