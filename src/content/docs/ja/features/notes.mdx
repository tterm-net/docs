## フォルダー

サイドバーでは、どのプロジェクトにもマシンの下に **ノート** があります。**ノート** の横の **+** でフォルダーを作ります。名前を付けて **フォルダーを作成** を押します。フォルダーの横の **+** を押すと、そのフォルダーに新しいノートが専用のタブで開きます。フォルダー自体をクリックしても、折りたたみと展開が切り替わるだけです。プロジェクトのページには、同じ操作がボタンとしてあります。**新規フォルダー** と、各フォルダーの **新規ノート** です。

<Screenshot name="notes-folders" alt="サイドバーの Client X：マシン db-1 とそのターミナル backups があります。「ノート」の下には、「tTerm が記録」の印が付いたフォルダー「ログ」と、Restore a backup と Deploy checklist 2/5 が入った Runbooks があります。「ノート」と Runbooks の横には「+」があります。" />

プロジェクトのページでフォルダーの横の **⋯** を押すと、**フォルダー名を変更** と **フォルダーを削除** があります。フォルダーは中のノートと一緒に削除されます。ウィンドウにそのノートが一覧で表示されるので、残したいノートは先に移動してください。

今のところ、どのプロジェクトのメンバーもあなただけなので、ノートが見えるのもあなただけです。そこにあるノートとフォルダーは、どれもあなたが書いたり、移動したり、削除したりできます。ノートのタイトルの下にも **あなただけが閲覧可能** と表示されます。

## 書く

新しいノートは、カーソルがタイトルにある状態で開き、**Enter** で本文に移ります。本文はブロックでできています。テキスト、見出し、リスト項目、チェックリスト項目、コード、区切り線です。**Enter** で新しいブロックが始まり、空の項目で押すとリストが終わります。

ブロックの先頭で Markdown を入力すると、ブロックがその意味どおりのものに変わります。

| ブロックの先頭で入力 | 変わるもの |
| --- | --- |
| `#` とスペース | 見出し |
| `-` とスペース、または `1.` とスペース | リスト項目 |
| `- [ ]` とスペース | チェックリスト項目（`- [x]` ならチェック済みの項目） |
| `` ``` `` | コード |
| `---` | 区切り線 |

ブロックの先頭以外では、Markdown は入力したまま残ります。空の行で **/** を入力すると、同じものを一覧から選べます：**チェックリスト**、**見出し**、**リスト**、**コード**、**区切り線**、**テキスト**。続けて文字を入力すると一覧が絞り込まれ、矢印キーで移動し、**Enter** で決定します。複数行のテキストを貼り付けるとブロックに分かれ、その中の Markdown も同じように読み取られます。

## コードとチェックリスト

コードブロックは行をそのまま保ちます。**Enter** でブロック内に新しい行を始め、**Tab** でスペースを 2 つ入れます。Mac では **⌘Enter**（そのほかでは **Ctrl+Enter**）でコードブロックを抜け、下に新しいブロックを作ります。コードブロックに貼り付けたテキストは、そのまま残ります。角にある **コピー** を押すとコードがコピーされ、一瞬 **コピーしました** と表示されます。

チェックリストの項目は、ボックスをクリックしてチェックします。チェックはすぐに保存され、項目の横に、誰がいつチェックしたかが表示されます。今日なら **あなた · 10:02**、それより前なら日付です。チェックリストの進み具合は、サイドバーでは 2/5、プロジェクトのページでは **5 件中 2 件完了** と表示されます。

## 保存

ノートは、入力が止まると少しして自動で保存されます。保存の状況はタブの右に表示されます：**保存中…**、**保存済み**、**未保存：接続がありません**。

同じノートを 2 台のデバイスで同時に書いても、どちらの変更も残ります。保存のたびに、その間に保存された内容とブロック単位でまとめられるからです。同じブロックやタイトルが両方で変更されたときだけ、その箇所にどちらを残すかをノートが尋ねます：**自分の内容を残す** か **もう一方の内容を残す** です。ほかの部分は、両方の変更が残ります。このまとめのために、tTerm は各ノートの直近 50 個のバージョンを保存しています。

接続がないときは、入力した内容は保存されるまでこのブラウザーに残り、ページは保存を試み続けます。タブを閉じたりページを再読み込みしたりしても、もう一度ノートを開けば内容は戻ります：**このノートに入力して保存されていなかった内容を復元しました。**

:::caution[サインアウトすると消えます]
**サインアウト** すると、ノートに入力してまだ保存されていない内容は、このブラウザーから消えます。
:::

## 移動、コピー、削除

ほかの操作は、ノートの横の **⋯** にあります。プロジェクトのページでも、ノートのタブの上部でも使えます。

- **フォルダー** – プロジェクトのフォルダーの一覧で、ノートがあるフォルダーにチェックが付いています。別のフォルダーをクリックすると、ノートがそこへ移動します。プロジェクトにフォルダーが 2 つ以上あるときに表示されます。
- **別のプロジェクトに移動…** – ウィンドウに、ほかのプロジェクトとそのフォルダーが一覧で表示されます。フォルダーを選んで、たとえば **「手順書」に移動** を押します。フォルダーのないプロジェクトでは、ノートがあったフォルダーと同じ名前の新しいフォルダーが提案されます。ノートのタイトル、本文、履歴は一緒に移り、チェックとそれを入れた人の記録も移ります。
- **Markdown としてコピー** – ノート全体をコピーします。タイトルは最上位の見出しになります。
- **ノートを削除** – 先に確認があります。削除したノートは元に戻せません。

ノートは検索でも見つかります。`n:` で始めてください。詳しくは[検索](../search/)をご覧ください。

## ログ

サイドバーでは、プロジェクトのフォルダーの先頭に **ログ** があり、**tTerm が記録** の印が付いています。中には、プロジェクトのマシンごとのログがあります。tTerm を通じてそのマシンで実行したすべてのコマンドが 1 日単位で並び、コマンドの下に追加したノートも一緒に入っています。ログは tTerm が記録し、誰も変更できません。行は 1 年間、コマンドの出力は 30 日間保存されます。詳しくは[マシンのログ](../log/)をご覧ください。
